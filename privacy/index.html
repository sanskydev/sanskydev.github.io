Privacy Policy

Effective date: November 26, 2026 · Operator: sanskydev · Contact: sansky.dev@gmail.com

Ringkasan Singkat (Bahasa Indonesia)

Situs sanskydev.github.io adalah situs statis tanpa cookie, tanpa JavaScript, dan tanpa pelacak pihak ketiga. Aplikasi integrasi API kami hanya digunakan secara internal oleh pemilik tunggal untuk menerbitkan video dan membaca metrik agregat milik 4 kanal resmi kami (Kalau Bercerita, Usut Bisnis, LazyFixLab, dan Glasswall Giants). Data hanya disimpan secara lokal di database milik operator, tidak pernah dibagikan atau dijual, dan dapat diminta untuk dihapus kapan saja melalui sansky.dev@gmail.com.

1. Scope and Purpose

This Privacy Policy explains how sanskydev (“we”, “our”, or “the operator”) handles data in connection with:

  • This umbrella website at https://sanskydev.github.io; and
  • Our single-owner internal publishing and analytics workflow used exclusively to manage our own four media channels: Kalau Bercerita (@kalaubercerita), Usut Bisnis (@usutbisnis), LazyFixLab (@lazyfixlab), and Glasswall Giants (@glasswallgiants).

We do not offer public user accounts, third-party SaaS access, or external logins. Only the channel owner authorizes and uses our developer applications.

2. Website Visitors

This website is served as plain static HTML and CSS via GitHub Pages. It does not set cookies, does not run JavaScript, does not embed third-party tracking pixels, and does not collect personal information from visitors. Standard web server access logs (such as IP address and request path) may be processed by GitHub Pages as our hosting provider in accordance with GitHub’s privacy practices.

3. Platform APIs Used

To upload original videos and review channel performance for our own four accounts, our internal workflow connects solely via official platform APIs:

  • YouTube Data API v3 — uploading videos, setting metadata, and reading published video IDs for our own YouTube channels.
  • YouTube Analytics API — retrieving aggregated channel and video performance metrics (such as views, watch time, and retention) for our own YouTube channels.
  • Instagram Graph API — publishing Reels/media and reading aggregated media insights for our own Instagram professional accounts.
  • Facebook Graph API — publishing video posts and reading aggregated Page/post insights for our own Facebook Pages.
  • TikTok Content Posting API — uploading and publishing original short-form videos to our own TikTok accounts.
  • TikTok Display API — retrieving basic profile information and aggregated video statistics for our own TikTok accounts.

Our use of Google/YouTube API data adheres to the Google API Services User Data Policy, including the Limited Use requirements. Because our internal workflow uses YouTube API Services, Google’s processing of data is also governed by the Google Privacy Policy.

4. What Data Is Stored and How It Is Used

We store only the minimum operational records required to track our own publishing schedule and measure editorial quality:

  • Published post and video identifiers (post IDs, platform URLs, and publication timestamps).
  • Aggregated channel and video performance metrics (such as views, likes, shares, comments count, watch time, and retention percentages).
  • OAuth access and refresh tokens for our own accounts, kept strictly in local operator-controlled environment configuration and never published or committed to source control.

All operational metrics and post IDs are stored exclusively in a private, local database on the operator’s workstation. We do not collect personal data of individual viewers, commenters, or third-party users.

5. No Sharing, Sale, or Third-Party Advertising

Data retrieved from YouTube, Instagram, Facebook, or TikTok APIs is never shared with third parties, never sold or rented, never transferred to data brokers, and never used for third-party advertising, cross-platform tracking, or user profiling.

6. Content Transparency & Disclosures

Across all four channels, we apply platform AI-content labels whenever synthetic or AI-assisted media is used, and we provide clear, honest disclosures for any affiliate links, sponsorships, or promotional material.

7. Data Retention, Revocation, and Deletion Requests

Published post IDs and aggregated metrics are retained locally only for as long as needed to evaluate channel performance. You may revoke API access at any time via the Google Security Settings page (or the connected-app settings of Meta and TikTok).

To request deletion of any stored data, report a privacy concern, or ask questions about this policy, please email sansky.dev@gmail.com with the subject line Data Deletion Request. We will review and confirm deletion within 7 business days.

8. Policy Updates

We may update this Privacy Policy to reflect changes in our internal workflow or platform API requirements. Any updates will be published on this page with a revised effective date.
